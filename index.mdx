The Zoom OAuth Sample App is a minimal Node.js Hello World project that walks you through the complete Zoom OAuth 2.0 authorization code flow. It shows how to redirect users to Zoom's authorization page, exchange the returned code for an access token, and make an authenticated API call to retrieve user profile data — all with zero runtime dependencies beyond Node.js itself.

## How it works

<Steps>
  <Step title="Clone and install">
    Clone the repository and install the single dev dependency (`nodemon`) with `npm install`.
  </Step>
  <Step title="Configure credentials">
    Create a `.env` file with your Zoom OAuth `CLIENT_ID`, `CLIENT_SECRET`, and `REDIRECT_URL`.
  </Step>
  <Step title="Start the server">
    Run `npm run start` — the Node.js HTTP server starts on port 4000 and automatically reloads on code changes.
  </Step>
  <Step title="Authorize and call the API">
    Visit `http://localhost:4000` in your browser. You'll be redirected to Zoom to authorize the app. After approval, the server exchanges the code for an access token and displays your Zoom user profile as JSON.
  </Step>
</Steps>

<Note>
  This sample app is intended for local development and learning purposes. Before deploying to production, review Zoom's [OAuth best practices](https://developers.zoom.us/docs/integrations/oauth/) and never expose your `CLIENT_SECRET` publicly.
</Note>
