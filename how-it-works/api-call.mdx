After the token exchange succeeds, the sample app immediately makes a single authenticated API call to Zoom: `GET https://api.zoom.us/v2/users/me`. This endpoint returns the profile of the user who authorized the app. The response is rendered as formatted JSON directly in the browser.

## The API Call Code

```javascript
const userInfoOptions = {
    hostname: 'api.zoom.us',
    path: '/v2/users/me',
    method: 'GET',
    headers: {
        'Authorization': `Bearer ${tokenBody.access_token}`
    }
};

makeHttpsRequest(userInfoOptions, null, (err, userBody) => {
    if (err) {
        console.error('Failed to get user data:', err);
        return;
    }
    res.writeHead(200, { 'Content-Type': 'text/html' });
    res.end(`<html><body><pre>${JSON.stringify(userBody, null, 2)}</pre></body></html>`);
});
```

## Request Details

| Property | Value |
|----------|-------|
| Method | `GET` |
| Host | `api.zoom.us` |
| Path | `/v2/users/me` |
| Auth header | `Authorization: Bearer <access_token>` |
| Required scope | `user:read` |

## The makeHttpsRequest Helper

The `makeHttpsRequest` function is defined at the top of the request handler. It wraps Node's built-in `https.request` into a clean callback-based interface, accumulating streamed response chunks and parsing the final result as JSON.

```javascript
function makeHttpsRequest(options, body, callback) {
    const request = https.request(options, response => {
        let data = '';
        response.on('data', chunk => data += chunk);
        response.on('end', () => callback(null, JSON.parse(data)));
    });
    request.on('error', error => callback(error, null));
    if (body) {
        request.write(body);
    }
    request.end();
}
```

This function is used for both the token exchange POST and the user info GET, keeping the networking logic consistent across both calls.

## Sample Response

A successful call to `GET /v2/users/me` returns a JSON object similar to the following:

```json
{
  "id": "abcde12345",
  "first_name": "Jane",
  "last_name": "Doe",
  "email": "jane.doe@example.com",
  "type": 1,
  "role_name": "Owner",
  "pmi": 1234567890,
  "use_pmi": false,
  "timezone": "America/New_York",
  "verified": 1,
  "status": "active"
}
```

</ResponseField>

<Tip>
  To call other Zoom API endpoints, replace the `path` in `userInfoOptions` and add the required scopes to your Zoom App Marketplace app. The `makeHttpsRequest` helper handles both GET and POST requests, so it can be reused for any additional Zoom API calls you add to the app.
</Tip>
